# Homebrew tap for Kodosi

```sh
brew install --cask johnkozaris/tap/kodosi
```

The cask installs `Kodosi.app` in `/Applications` and links the `kodosi` command. Kodosi
updates itself, so `brew upgrade` leaves it alone.

Each release of [Kodosi](https://github.com/johnkozaris/Kodosi) writes `Casks/kodosi.rb`
here. There is no release yet.
